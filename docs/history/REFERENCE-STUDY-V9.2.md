# V9.2 Reference Study — principles applied, not copied

This checkpoint compounds the existing V8.2 → V9 → V9.1 system. No existing proof, SEO, contact Worker, evidence architecture, URLs or conversion routes are intentionally removed.

## New references studied on 11 Aug 2026

- **Useless Fund** — strong concept in the first sentence; operating-system/status language as storytelling; restrained playfulness; the interface itself communicates the idea.
- **Trake** — instant value with no signup; a three-step journey; browser-local processing explained as a trust benefit; concrete output before feature overload.
- **Framer 2026** — the product demonstrates itself; modular modes; visible performance thinking; changes stay editable and under human control.
- **Juggle** — pain-first positioning; raw conversation becoming an organised next action; client/context-first information architecture; privacy is part of the product story, not footer copy.
- **OhhMyDesign** — unmistakable headline; live/time context; conversational process demo; sharp “same brief, different outcome” comparison; visible human ownership and proof close to the claim.
- **Builders Table** — numbered chapter architecture; role-based entry; concrete “what to expect”; progression from interest to action; event-like momentum without hiding practical details.
- **Aspen Search** — high-signal positioning; category fluency; specific proof above generic claims; quality-over-volume; the person you meet is the person doing the work.

## How those lessons became Moyosore-specific features

1. **Decision Router** — visitors can type one messy commercial problem and get a transparent, local first route. No upload, no account, no fake AI claim.
2. **Same Signal, Better Question** — interactive examples show the difference between a surface read and FIELD × SYSTEM reasoning.
3. **Live Context Desk** — true WAT time, visitor local time, and public GitHub freshness; no invented availability or follower counters.
4. **Start-page Route Me** — one tap turns visitor intent into the shortest useful next page.
5. **Raw Signal → Useful Move** — a tactile four-step mini operating system that teaches by interaction.
6. **Build Integrity** — performance, reduced motion, public freshness and evidence boundaries are explained openly.
