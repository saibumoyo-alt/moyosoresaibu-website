# Deploy Premium Human Touch 1.6

Use this package for one upload/deployment.

## Includes
- full website
- start page
- premium motion and subtle interactive graphics
- hand-drawn underline and arrow accents
- paper/ink texture
- visible website URL on home and start heroes

## Deploy
1. Extract the ZIP.
2. In GitHub, open your website repository.
3. Click **Add file → Upload files**.
4. Upload the extracted contents directly into the repository root.
5. Commit to `main`.
6. Wait for Cloudflare Pages to finish deploying.
7. Hard refresh both `/` and `/start/`.

## After deploy, confirm
- no `Checking…`
- no `WAT --:--`
- no `Sound` toggle
- premium motion is subtle and smooth
- cards lift slightly on desktop hover
- website URL appears in both hero areas
