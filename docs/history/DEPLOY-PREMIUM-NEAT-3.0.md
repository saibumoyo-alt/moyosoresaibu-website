# Deploy Premium Neat 3.0 — once

1. Back up your current GitHub repository.
2. Extract `Moyosore-Saibu-Premium-Neat-3.0-Deploy-Once.zip`.
3. In GitHub choose **Add file → Upload files**.
4. Upload the extracted contents directly into the repository root. Do not upload the outer folder.
5. Commit directly to `main` with: `Launch Premium Neat 3.0`.
6. Wait for Cloudflare Pages to show a successful Production deployment.
7. Hard-refresh `/` and `/start/`.
8. Check Home, Start, Experience, Projects, Insights, Contact, Evidence and both case studies.

Expected result: no word underlines anywhere, clean glass surfaces, interactive proof graphs, clear beginner-first copy, and no broken live placeholders.
