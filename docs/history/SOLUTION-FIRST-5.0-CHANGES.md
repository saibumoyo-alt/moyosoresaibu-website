# Solution-First 5.0

## Positioning decision

The website now positions Moyosore Saibu around the problems he helps solve, not around an employer or job title. Guinness Nigeria and other roles remain on Experience, case-study and Evidence pages as proof of real responsibility and outcomes.

## New visitor journey

1. Start with the visitor's problem.
2. Show the problem-solving method.
3. Show evidence and case studies.
4. Offer a clear way to bring a real problem.
5. Keep career/employer context available for verification rather than using it as the identity headline.

## Primary problem areas

- Sales execution
- Customer growth and retention
- Route-to-market and coverage
- Decision systems, analytics and AI-assisted workflows

## Main copy changes

- Home H1: “I help turn commercial problems into clear growth moves.”
- Home primary CTA: “Bring me a problem.”
- Projects navigation label becomes “Solutions” while the stable `/projects` URL is retained.
- About leads with problem-solving philosophy rather than current employment.
- Experience is explicitly framed as evidence behind the problem-solving.
- Contact begins with “Bring me the problem.”
- Start page routes visitors by problem, not by Work/Lessons/Tools/About.

## Technical constraints preserved

- Static site architecture
- Existing Cloudflare Worker contact form
- Existing evidence pages and case studies
- Existing responsive image strategy
- Existing lightweight shared CSS and JavaScript
- Existing clean URLs and redirects
