# Reference Study → Moyosore V9

Studied on 11 Aug 2026. The goal was to extract durable experience-design principles, not copy visual assets or source code.

## 1. Leedlime

### What works
- Hero begins with the user's uncertainty/pain, then immediately states the outcome.
- Product proof appears close to the hero rather than being buried.
- The "three steps" section reduces a complex product to a short mental model.
- Freshness is part of the proposition (e.g. current/updated status), which creates trust.
- Repeated CTAs are consistent and low-friction.

### Moyosore adaptation
- `Three moves between signal and result`: Notice → Decide → Execute.
- Public GitHub freshness signal instead of invented live activity.
- More visible Start Here route and evidence-first navigation.

## 2. Digital Original XR

### What works
- The page feels like an experience, not a document.
- "Two modes" gives visitors agency while preserving one product story.
- The journey is progressively revealed instead of explained all at once.
- Strong scroll pacing alternates big statements with interactions and details.

### Moyosore adaptation
- `Two modes · one operator`: Field Mode ↔ System Mode on the main site.
- `Current ↔ Evergreen` on the Start page.
- More deliberate rhythm between statement, interaction, proof and action.

## 3. Hue & Code

### What works
- Memorable two-part positioning makes the promise easy to repeat.
- Proof and "shipped/live" language reduce abstraction.
- The four-step process makes working together feel predictable.
- Quality attributes (speed, responsive behaviour, accessibility, SEO) are treated as part of the product rather than technical afterthoughts.
- Personal accountability is visible near conversion points.

### Moyosore adaptation
- `Field instinct. System discipline.` as a repeatable two-part idea.
- Four-step process: Understand → Choose → Execute → Review.
- V9 kept the existing light, framework-free architecture rather than adding a large frontend dependency.
- Accessibility behaviour for tabs and reduced motion is preserved.

## What we deliberately did NOT copy
- No layouts traced pixel-for-pixel.
- No logos, product mockups, photographs, animations, icons or code from the reference sites.
- No reference-site copy reused as Moyosore copy.
- No fake testimonials, live counters, customer logos or invented real-time metrics.

## V9 north star

The main website should answer: **Can this person do the work, and what evidence supports that?**

The Start page should answer: **Who is Moyosore, what will I get here, what is current, what stays useful, and where should I go next?**
